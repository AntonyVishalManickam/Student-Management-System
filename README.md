# Student Management System (Desktop GUI)

A desktop application built with Python, Tkinter, and SQLite to manage college student records, attendance, and course marks.

## Features
- **Full CRUD Operations**: Create, Read, Update, and Delete student records.
- **Interactive UI**: Real-time tabular display using Tkinter `Treeview` with auto-populating input forms.
- **Data Integrity**: Enforces unique roll numbers and validates empty input fields.
- **Database Integration**: Safe parameterized SQL queries using SQLite.

## Tech Stack
- **Language**: Python 3
- **GUI Framework**: Tkinter
- **Database**: SQLite3

## How to Run
1. Clone the repository: `git clone https://github.com/AntonyVishalManickam/Student-Management-System.git`
2. Run the application: `python app.py`
